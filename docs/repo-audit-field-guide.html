Repo Audit Field Guide

What to check to find issues in a repository, broken out by architecture — single repo, monorepo, polyrepo, microservices, the smaller special-purpose repo kinds, the portfolio/process metrics that sit above any one repo, and a single pull request at review time. Each criterion names a concrete tool or metric, not just an idea.
